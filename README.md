# GitHub Pages 介绍页

这是一个零依赖的静态介绍页。部署前请在 `index.html` 中替换：姓名、城市、项目名称、邮箱与社交链接。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库（个人主页建议命名为 `你的用户名.github.io`）。
2. 将此目录推送到该仓库的 `main` 分支。
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，并选择 `main` / `root`。
4. 等待片刻后，从 Pages 页面给出的链接访问网站。

本地预览：直接用浏览器打开 `index.html` 即可。
